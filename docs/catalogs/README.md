# O11 foundation catalogs

One focused catalog per verified target foundation. Start from `templates/UI_FOUNDATION.template.json`. It is project-specific evidence, not an exhaustive dump or universal platform schema. Actual module/Screen/UI Flow theme, installed dependency contracts and relevant source hashes determine reuse.

Use the [CheatSheet source index](../references/cheatsheets/README.md) for the stored Developer PDF (general concepts) and UI reference (pattern/class/token candidates). Record candidate source separately from installed evidence. Use official Cheat Sheet for discovery: https://outsystemsui.outsystems.com/OutSystemsUIWebsite/CheatSheet . Verify classes, tokens and public actions against the installed O11 version. The general Developer Cheat Sheet PDF is learning material, not a UI token/signature registry.

No generated catalog is supplied for WHT: uploaded snapshots are historical and this review has no live Model API access. Populate actual contracts with the primary local operator, read-only.
